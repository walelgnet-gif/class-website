# class-website

## Accessibility Fixes
- I replaced `<p>` tags with heading tags (`<h1>`-`<h3>`) so screen readers can accurately navigate through the web page without being mislead.
- I Verified all text and background color combinations using the WebAIM Contrast Checker to ensure they meet WCAG AA standards.

## Visual Design (Gestalt Principles)
- **Proximity:** I used proximity to group my greeting and bio text closely together next to my profile image, while separating my navigation buttons and individual project/timeline sections with clear spacing.
- **Similarity:** I used similarity by styling my navigation buttons with identical pill shapes, colors, and typography, and maintaining a consistent dark navy theme and icon style across all three pages.

## Accessible Contact Form
- I added a contact form on About.html using explicit <label> elements, <fieldset> and <legend> groupings, and accessible error states.
